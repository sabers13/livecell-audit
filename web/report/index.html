A quality check for the images that teach AI.

Researchers mark cells in microscope images so an AI model can learn to recognise them. This project checks the images and their labels before they are used in an experiment.

A fair check should use examples the model has not already learned from.

These are the same source image. It appears in both groups.

Why it matters

Think of checking a student's progress with a question they already practised. Familiar examples can make the result look better than it would on new ones.

What needs attention

Keep each source image in one group for this evaluation, and record how the groups were chosen. Preserve the original data so the change can be checked.

This overlap is called data leakage. This review has not measured its effect on the model’s results. The separate final test group had no matching filenames with either group.

    How the audit works.

    The aim is to make data problems visible before they become part of an experiment.

    1. Step 1

      Read the source files

      Match each microscope image to the file describing its cell labels.

    2. Step 2

      Check the examples

      Look for reused images, missing files, and labels that need a closer look.

    3. Step 3

      Explain the findings

      Show the evidence and recommended review action, keeping a record of every change.

    What this report contains

    The repeatable audit ran over the downloaded snapshot and produced this page, the finding list, and the derived validation policy below. It does not train a model, change model scores, or correct the dataset.
