Overview Try it Results

Checking the data used to train AI.

I built a Python tool that checks cell images and their labels, then gives scientists a clear list of examples to review.

Checked on 5,239 images from Sartorius’ public LIVECell dataset.

30 reused images
The same photo sits in the learning and the checking group, which can make validation scores look better than they are.
9 images flagged for review
Very few cells are marked. A scientist should review these examples.

Both issues were first reported on GitHub (#26, #21). My tool reproduces them from the raw files and tracks them with evidence.

What I built

  • A repeatable data pipelinePython checks with automated tests.
  • A comparison of methodsMachine learning did not beat a simple label count. The tests favour counting by design, and the results say so.
  • A report you can verifyEvery finding connects to its evidence.

A fair check should use images the model has not already learned from.

These are the same source image. It appears in both groups, each time with a different version of its cell labels.

Why it matters

Think of checking a student with a question they already practised. Familiar examples can make the result look better than it would on new ones.

What needs attention

Keep each source image in one group for this evaluation protocol, and record how the groups were chosen. Preserve the original data so the change can be checked.

This overlap is called data leakage. It affects validation scores; the separate final test group had no overlapping filenames with either group. The dataset authors annotated some images twice and kept both versions (issue #14); here the two versions ended up in different groups. This project has not measured the effect on a model’s results.

Does machine learning help? An honest comparison.

Four ordering methods are compared at the same review budget. The simple low-count check is the default because it is transparent and, on these measurements, it performed best. Both measurements are defined by label count, though, so they favour it by design.
