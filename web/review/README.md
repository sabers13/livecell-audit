# LIVECell review website

A static, offline review website built from one completed release run of the
audit, ranking and evaluation (currently `20261018T231214Z-0e359b9bf088`). Open
`index.html` directly (`file://`) or serve the directory:

```bash
python3 -m http.server --directory web/review 8321   # → http://localhost:8321/
```

There is no build step, no framework, no network call and no backend.

## Files

- `index.html`, `assets/review.css`, `assets/review.js` — hand-written page, styles and
  interaction.
- `assets/guided-shared.png`, `assets/guided-sparse.png` — PNG copies of the two
  guided-example TIFFs (no overlay drawn in them).
- `data/site-data.js`, `data/rankings.js` — generated data as script globals
  (`window.LIVECELL_REVIEW`, `window.LIVECELL_RANKINGS`), so the page works from
  `file://`.
- `data/curated-examples.json` — the 39 illustrated examples; the input of the preview
  render.
- `previews/` — 39 server-rendered PNG previews (native 704 × 520 px) and, for the 30 dense images,
  `*.labels.png` layers with every supplied outline.
- `downloads/` — the run's verified documents, copied unchanged, plus `ranking-pool.csv`.
- `THIRD_PARTY_NOTICES.txt` — licence, change notice and upstream credits.

Everything except the three hand-written files is generated by
`tools/build_review_site.py` inside the release run and checked by
`tools/check_review_site.py`. To regenerate, run `tools/run_release.sh` and copy the
run's `site/` directory here. See `docs/11_review_interface.md` for inputs, the example
selection rule, the preview contract and the checks.

## Honest scope

- No health score, no invented percentage, no "run audit" control.
- Scores are relative review priorities, never probabilities that a label is wrong. The
  nine known cases are a regression exercise, not recall.
- The simulated precision@K and AUC values are simulation metrics; both tests are defined
  by label count. Real-world precision is unmeasured.
- Yellow outlines are the supplied annotation polygons, not cell boundaries detected by
  this project.
- No reviewer judgment is present: the frozen review sample ships with blank judgment
  fields.
